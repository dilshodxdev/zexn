# Stitch dizayn tokenlari

Google Stitch loyihasidan olingan dizayn qiymatlari (workspace ekrani).

## 1. Ranglar

| Token                 | Qiymat                      | Stitch'da ishlatilgan joy                                |
| --------------------- | --------------------------- | -------------------------------------------------------- |
| `--color-brand`       | `#d9f944`                   | Asosiy aksent (tugmalar, faol tablar, XP bar, yulduzlar) |
| `--color-brand-hover` | `#e6ff5e`                   | Tugma hover holati                                       |
| `--color-brand-soft`  | `rgba(217, 249, 68, 0.15)`  | Yengil fonlar, badge fonlari, border aksent              |
| `--color-bg`          | `#181a1b`                   | Sahifa asosiy foni                                       |
| `--color-surface`     | `#1e2022`                   | Header, sidebar va workspace bloklari foni               |
| `--color-surface-alt` | `#242729`                   | Kartochkalar, kirish maydoni, chat xabarlari foni        |
| `--color-text`        | `#f1f5f9`                   | Asosiy matn foni (oq/och kulrang)                        |
| `--color-text-muted`  | `#94a3b8`                   | Ikkinchi darajali matn va tavsiflar                      |
| `--color-line`        | `rgba(255, 255, 255, 0.08)` | Chegara chiziqlari (border-white/5, border-white/10)     |
| `--color-ok`          | `#22c55e`                   | Muvaffaqiyat va faol holatlar (avatar glow, online)      |
| `--color-ok-soft`     | `rgba(34, 197, 94, 0.15)`   | Muvaffaqiyat xabarlari foni                              |
| `--color-warn`        | `#f59e0b`                   | Ogohlantirish holati                                     |
| `--color-warn-soft`   | `rgba(245, 158, 11, 0.15)`  | Ogohlantirish foni                                       |
| `--color-danger`      | `#ef4444`                   | Xatolik va tozalash holatlari                            |
| `--color-danger-soft` | `rgba(239, 68, 68, 0.15)`   | Xatolik foni                                             |
| `--color-info`        | `#1e60f0`                   | Qo'shimcha axborot va havolalar (accent)                 |
| `--color-info-soft`   | `rgba(30, 96, 240, 0.15)`   | Axborot foni                                             |

## 2. Radius

| Token           | Qiymat           | Stitch'da ishlatilgan joy              |
| --------------- | ---------------- | -------------------------------------- |
| `--radius-sm`   | `0.375rem` (6px) | Kichik elementlar                      |
| `--radius-md`   | `0.5rem` (8px)   | Standart elementlar, kirish maydonlari |
| `--radius-lg`   | `0.75rem` (12px) | Ikon tugmalari (`rounded-xl`)          |
| `--radius-card` | `1rem` (16px)    | Kartochkalar (`rounded-2xl`)           |
